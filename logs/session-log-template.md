## Logging rules

- Log the exact reps achieved on every work set.
- If you changed tempo, pauses, range of motion, or rest, write that down.
- If form broke down, note it instead of pretending it was a clean progression.
- Keep notes short. The important data is load, reps, effort, and what changes next time.
- For Lower A/Lower B, always include leg readiness and any running/padel done in the prior 24 hours.
